시작하기

Mardocle은 로컬 Markdown 문서를 읽는 데 집중합니다. 파일을 열고, 편안하게 읽고, 필요한 내용을 찾아보세요.

왜 Mardocle인가요?

긴 문서도 목차와 검색으로 자연스럽게 탐색할 수 있습니다.

Ctrl+F문서 안에서 찾기

읽기에 집중

이런 문서를 읽을 때 잘 맞습니다.

프로젝트 문서

README와 기술 문서를 파일 탐색기에서 바로 열어 읽습니다.

긴 문서 탐색

목차와 검색으로 원하는 제목과 문장을 빠르게 찾아갑니다.

로컬 문서 보관

계정이나 동기화 없이 내 PC의 문서를 읽을 수 있습니다.

알려드려요. Mardocle은 Markdown을 편집하거나 클라우드에서 공동 작업하는 도구가 아닙니다.

핵심 기능

문서 읽기의 흐름을 끊지 않습니다.

열기부터 탐색, 가독성 조절, 인쇄까지. 읽는 순간에 필요한 도구만 담았습니다.

01

빠른 파일 열기

파일 열기, 드래그 앤 드롭, 명령행으로 Markdown과 텍스트 파일을 엽니다.

02

긴 문서 탐색

자동 목차와 본문 찾기로 필요한 제목과 문장으로 이동합니다.

03

나에게 맞는 가독성

밝은·어두운 테마, 글자 크기, 줄 간격, 본문 폭을 조절할 수 있습니다.

04

Markdown 표현

표, 체크리스트, 코드 블록, 각주 등을 읽기 편하게 표시합니다.

05

읽던 곳에서 다시

최근 파일과 마지막 읽기 위치를 기억하고, 외부 변경도 알려 줍니다.

06

인쇄와 PDF

Windows 인쇄 기능으로 문서를 인쇄하거나 PDF로 저장할 수 있습니다.

안전한 기본값

신뢰할 수 없는 문서도
열 수 있다는 전제에서.

Mardocle은 문서를 읽는 앱입니다. 웹 브라우저처럼 문서 안의 HTML이나 임의의 로컬 경로를 실행하지 않도록 기본 동작을 제한합니다.

구현과 보안 정책 보기 ↗
  • ✓
    raw HTML은 렌더링하지 않습니다.

    문서 안의 HTML은 실행 가능한 화면이 아닌 텍스트로 표시합니다.

  • ✓
    문서 폴더 밖의 상대 경로를 제한합니다.

    상대 파일 경로는 현재 문서의 부모 폴더 내부에서만 허용합니다.

  • ✓
    외부 이미지는 기본적으로 차단합니다.

    필요한 경우에만 설정에서 선택적으로 허용할 수 있습니다.

  • ✓
    외부 링크 프로토콜을 제한합니다.

    http, https, mailto만 외부로 열 수 있습니다.

이 정책이 모든 위험을 없앤다는 뜻은 아닙니다. 출처를 알 수 없는 파일은 Windows 보안 정책에 따라 주의해서 다루세요.

FAQ

자주 묻는 질문

더 자세한 내용이나 문제 해결은 GitHub Issues에서 알려 주세요.

어떤 파일을 열 수 있나요?

.md, .markdown, .txt 파일을 지원합니다.

문서를 수정할 수 있나요?

아니요. Mardocle은 문서를 안전하고 편안하게 읽는 데 집중하는 읽기 전용 뷰어입니다.

인터넷이나 계정이 필요한가요?

핵심 문서 읽기 기능은 로컬에서 동작하며 계정이 필요하지 않습니다. 외부 이미지나 외부 링크를 열면 네트워크 연결이 사용될 수 있습니다.

설치 중 문제가 생기면 어떻게 하나요?

설치 파일이 공식 릴리스로 게시된 뒤, 앱 버전과 Windows 버전을 포함해 GitHub Issues에 알려 주세요. 문서 내용이나 민감한 파일 경로는 공개 이슈에 올리지 마세요.

기능을 제안하거나 버그를 보고하려면 어디로 가야 하나요?

Mardocle GitHub Issues↗에서 알려 주세요.
